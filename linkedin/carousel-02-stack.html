Arquitectura

Domain-Driven Design, no spaghetti.

Capa de dominio pura, application services con Unit of Work, infraestructura intercambiable, presentation web aislada.

agnor/
├── domain/ # entidades, puertos
├── application/services/ # lógica de negocio (UoW)
├── infrastructure/ # repos, LLM, WhatsApp, voice
├── presentation/web/ # FastAPI + Jinja2 + React SPA
└── db/ # SQLAlchemy models, migrations

Backend

FastAPI + PostgreSQL 16, async-first.

⚡ FastAPI
🐍 Python 3.12
🐘 PostgreSQL 16
📚 SQLAlchemy ORM
🔄 Alembic Migrations
⏰ APScheduler

Tests contra PostgreSQL real (no mocks que mienten). Connection pooling, soft-deletes, índices afinados, query plans revisados.

Capa de IA

Claude + Retell, no wrappers de OpenAI.

Anthropic Claude para razonamiento estructurado (perfilamiento, matching, summarización). Retell LLM para voz en tiempo real con WebSocket.

🧠 Anthropic Claude API
🎙️ Retell LLM (voz)
🔄 Exponential backoff
📦 Prompt caching
🛡️ Output schemas
🔗 Tool use nativo

Integraciones

APIs nativas, no Zapier.

📲 Meta WhatsApp Cloud
🛒 Mercado Libre API
📅 Google Calendar OAuth
📊 Google Sheets API
📧 SendGrid Email

DevOps

🐳 Docker
🚀 Coolify CD
