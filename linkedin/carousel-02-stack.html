BACKEND № 03
FAST · ASYNC · TYPED

Async-first sobre PostgreSQL real.

FastAPI Python 3.12 PostgreSQL 16 SQLAlchemy ORM Alembic Migrations APScheduler

Tests contra PostgreSQL real, no mocks que mienten. Connection pooling, soft-deletes, query plans revisados, soft-delete en propiedades para nunca perder histórico.

INMOBI.AI 03 / 08
FRONTEND № 04
SPA + JINJA HÍBRIDO

Type-safe end to end.

React 18 TypeScript strict Tailwind CSS shadcn/ui Redux Toolkit Recharts

SPA con Redux para estado complejo. Tailwind con design tokens del brand. Componentes accesibles por default. Jinja2 para vistas administrativas que no necesitan reactividad.

Anthropic Claude para razonamiento estructurado: perfilamiento, matching de propiedades, summarización de llamadas. Retell LLM para voz en tiempo real con WebSocket.

INTEGRACIONES № 06
APIs NATIVAS

Sin Zapier. Sin middleware caro.

Meta WhatsApp Cloud API Mercado Libre API Google Calendar OAuth Google Sheets API SendGrid Email Twilio Voice

Cada integración con webhook fail-closed: si la firma no verifica, se rechaza. Cero zaps, cero costo recurrente extra.

INMOBI.AI 06 / 08
DEVOPS № 07
DEPLOY AUTOMATIZADO

Push a main. Listo. Sin downtime.

Docker Coolify CD Traefik proxy Let's Encrypt SSL Structured logging Pytest + Playwright

Coolify rebuild + cutover blue/green en segundos. Rollback con un click si algo falla. La rama main es la verdad — tests-pg pasan antes de cada push.
